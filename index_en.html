C Compiler

Late 2024

First-year team project (4 members). We developed a C to x86-64 assembly compiler. OCaml libraries were used for lexical analysis and parsing to generate an intermediate JSON abstract syntax tree. A Python backend then interprets this JSON file to emit functional assembly code matching the original C program behavior. Supported features include pointers, local/global variables, arithmetic operations, arrays, functions, printf/scanf, conditional statements (if/else), while loops, and dynamic memory allocation (malloc).

2023 - 2024

Preparatory class research project (MPI*) presented for French Grandes Écoles oral entrance exams. The study focused on applying the NEAT (NeuroEvolution of Augmenting Topologies) genetic algorithm to autonomous driving.
